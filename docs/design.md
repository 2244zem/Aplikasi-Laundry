# ScaleWash Design Guide

## Brand Intent

ScaleWash should feel clean, operational, and trustworthy. The product is not a marketing-only site; it is a working SaaS dashboard for laundry owners and customers, so the interface should prioritize status clarity, fast scanning, and low-friction task completion.

## Core Visual Tokens

| Token | Value | Usage |
| --- | --- | --- |
| Primary blue | `#16587B` | Header text, primary actions, active navigation |
| Light surface | `#EAF6FF` | Soft dashboard background and selected rows |
| Neutral text | `#1F2933` | Main body copy |
| Muted text | `#64748B` | Secondary labels and helper text |
| Success | `#15803D` | Paid, completed, active subscription |
| Warning | `#B45309` | Pending payment, pending confirmation |
| Danger | `#B91C1C` | Expired subscription, failed payment |

## Typography

- Use bold weight `700` for page titles, dashboard section titles, and primary status labels.
- Keep dashboard headings compact. Reserve large type for first-screen product or brand moments.
- Use short, direct Indonesian operational labels: `Pesanan Baru`, `Dicuci`, `Disetrika`, `Selesai`, `Langganan Aktif`.

## UI Rules

- Prefer dense but organized admin views: order table, status filters, payment state chips, and printer status.
- Use icons for repeated tools such as print, refresh, search, settings, and download.
- Avoid nested cards. Use full-width dashboard bands and table surfaces.
- Thermal printer output should use a monospace font and a `58mm` or `80mm` receipt layout.
